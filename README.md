# スマホ映像モニター

教材の完成コード（ステップ10のApp.tsxとステップ11のCSS）を配置しています。

## 実行

Node.js 24で `npm ci`、`npm run dev`。VS CodeターミナルのNetworkに表示されるHTTPSのURLをPCで開きます。
自分のPCの開発サーバーであることを確かめ、自己署名証明書の警告画面の操作は利用者自身で行ってください。
PCにPeer IDとQRコードが表示されたら、同じネットワークのスマホでQRコードを読み取ります。
スマホでカメラを許可し、PCに映像が出るか確認します。入力欄の文字を変えて画面をタップすると、PCの対応する映像の上に文字が表示され、上昇して消えます。
PCを再読み込みするたびにスマホで新しいQRを読み直してください。
テザリングはスマホの通信量を消費します。端末同士の通信が制限されている場合は接続できないことがあります。

## 公開

GitHubリポジトリのSettings → Pages → SourceはGitHub Actions。
VS Codeソース管理でコミット・変更の同期を行い、ActionsのDeploy Vite to GitHub Pagesが緑になるまで待ちます。
公開URLは https://se0810.github.io/peerjs-practice/ です。
公開後もPCのQRをスマホで読み、映像・文字・切断時の表示を実機で確認してください。

## 教材どおりに残した発展課題

消えた文字をeffects配列から削除する処理、入力欄タップで送信しない処理、再接続、縦横比に依存しない上昇距離などは教材どおり未実装です。
